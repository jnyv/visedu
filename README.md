# VisEdu

> See it. Understand it. Learn it.

VisEdu is a visual learning platform designed to help learners
understand difficult academic IELTS content before working with
the original material.

## The Idea

Traditional learning often asks students to process difficult
text or audio immediately.

VisEdu introduces a different sequence:

**SEE → UNDERSTAND → PRACTICE**

Learners first experience the context through faithful visual
storytelling, then work with important vocabulary, and finally
return to the original IELTS material and questions.

## Current Focus

The current prototype focuses on:

- IELTS Reading
- Visual context
- Contextual vocabulary
- Original reading passages
- IELTS-style practice
- Answer review
- Learning progress
